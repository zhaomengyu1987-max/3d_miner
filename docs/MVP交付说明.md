# MissionOps 可玩 MVP 交付说明

> 提交: 0951221(主线) · 137 断言双轮全绿 · 2026-10-05

## 试玩说明(10 步以内)

1. **启动游戏**(需要先建造一座雇佣兵巢穴,或调用 `MissionOps.trial_setup()` 进入试玩档)
2. **按 F6**(或点击巢穴建筑)打开**行动中心**
3. 切到**酒馆**页 → 点一名候选人的**[雇佣]**按钮
4. 回到**行动**页 → 点**[+ 新建队伍]**(自动用空闲舰长建队)
5. 在任务列表**点选一个任务**(如"冰带深处勘测")
6. 右侧查看详情(成功率/奖励/条件) → 点**[派遣]**
7. 等待倒计时(试玩模式下÷10加速) → 结算后底部显示结果
8. 切到**舰船装配**页 → 点**[+ 启用舰船]** → 从库存点**[安装]**装上装备
9. 回到队伍列表 → 把舰船加入队伍(通过装配页)
10. 再次派遣——装了T1+升级装备的任务时长更短

## 已完成的玩法循环

```
巢穴/F6 → 行动中心
  ├─ 酒馆: 雇佣/解雇舰长
  ├─ 舰船装配: 启用/退役舰船 + 四槽装备安装/卸下
  ├─ 行动: 选队伍→选任务→查看详情→派遣
  ├─ 等待: 倒计时显示在底部
  ├─ 结算: 战报弹窗自动弹出(LOOT红绿底色行)
  ├─ 成长: T1+升级(材料→装备升级→时长-15%)
  └─ 再派: 成长后再次派遣体验差异
```

## 三件建议重点体验的事

1. **组队选择是否有意义**: 不同舰长/装备组合 vs 不同任务门槛,选择是否影响成败
2. **等待与收益是否匹配**: 任务时长 vs 奖励量级,是否值得等
3. **是否愿意再派一次**: 完成一轮后是否有动力再次派遣

## 已知小问题(不阻断)

- 装配台无拖拽(点按钮安装/卸下,非拖拽交互)
- 技能效果为 placeholder(仅入表+扣点,不影响计算)
- 试玩档未完全隔离存档文件(trial_initialized 标记制)
- 数值未平衡(全部占位值)
- 非核心页面无筛选/排序
