## 1. 摘要

**MissionOps(探索派遣系统)是独立于挖矿/制造/商业主系统、独立于世界系统的放置类"远征副本"模块**:玩家造船、雇舰长、组编队,把编队派出去接探索/战斗/打捞/护航/信号委托,按现实时间计时,种子掷骰结算,带回探索点、发现物、蓝图碎片、远征材料与小额信用点。

一句话:**玩家亲自挖矿是发动机,MissionOps 是第二台——广度与进度,绝不替代核心体验。**

关键事实速览:

| 维度 | 结论 |
|---|---|
| 功能定位 | 探索系统(远征副本),非经济自动化 |
| 时钟 | 墙钟制(离线照走,读档按 saved_at_wall 补结算) |
| 随机 | 全链种子 RNG,结果可复现、争议可查 |
| 装备语义 | 资格门槛("不放装备就跑不了"),百分比只归 T2/稀有 |
| 舰长 | Starsector 式技能制(普通 5级3技能/稀有 7级5技能) |
| 容量 | 空间站建筑「雇佣兵巢穴」等级 = 行动舰队数(1~4) |
| 任务供给 | 三层:常驻(×1.5 冷却)/轮换(30min)/发现地点(M3) |
| 战报 | EVE killmail 式 KILL REPORT(简化结构×渲染风,内容 seed 随机生成) |
| 存档 | 前置公共件 GameSave(节注册制 JSON),当前全项目零持久化 |
| 开发纪律 | 蓝图阶段实现代码禁入 main;实现开独立 worktree |

## 2. 溯源:为什么是 MissionOps

源于竞品分析([大鲸鱼-深空放置](https://yahzj.github.io/Deepseek-EVE/),28 天高速迭代的 EVE 文字挂机):

- 其 AI 分身 = 自动挖矿/打捞循环 + 离线结算,是**没有手动玩法的游戏**的发动机;
- 我们有 3D 亲自挖矿这个核心体验,照搬"AI 替你挖"等于游戏劝玩家别玩核心循环;
- 竞品的**远征任务**(锁编队火力、计时、掷骰)才是可移植的部分——把它抽出来放大成独立系统,即 MissionOps。

防御性设计由此推导(蓝图 §0 三铁律):不自动化核心循环、奖励走进度/发现/稀缺(货币 ≤ 同时长手动收益 15%)、出任务 = 船三重锁定。

期间否决的方案:雇佣舰长挂 Economy 做经济克隆(自我贬值);AI 自动挖矿(同);巡航倒货(同)。

## 3. 架构与独立性

```
Economy(钱包 pay/earn、库存 grant_item、hive_level()、船锁互查)
   ▲ 单向依赖(只调这三个口)
MissionOps(状态机/任务板/编队/舰长/结算)
   │ 信号:mission_completed / discovery_made / captain_state_changed / pirate_suppressed(阶段3)
   ▼ 想听的人听
WorldState(零依赖;M4 起经适配器注入"阵营委托",MissionOps 不感知来源)
```

- **对世界系统零依赖**(§1 接触面清单):任务文案不出现具体阵营名,委托方一律"深空探索协会"占位。
- **数据结构**(§3):`missionops` 存档节 = exploration(EP/等级/发现物) / captains(含 rare/skills/points) / recruit_pool / teams / **fleet(舰船名册:001号自动编号,fitted 四槽)** / board(三层供给状态) / active(在途:started_wall+ends_wall+seed) / stats。
- **时钟与离线**(§6):墙钟制;离线补结算 = 对 ends_wall ≤ now 的在途任务逐个按 seed 结算,结果与在线逐位一致;不需要竞品那套 8h 离线封顶/30s 分片(我们离线只有离散任务,无连续模拟)。

## 4. 子系统决策记录

### 4.1 舰船启用与命名(§14)
建造完成的船默认是商品;「启用」生成实例入名册,**自动编号 001号/002号…**(退役不回收舷号,正式命名规范待拍板)。退役自动卸装回仓。

### 4.2 子系统装备(§15)——最大的一次设计反转
- 四槽:**能源/电子/武器/防御**(船长四分法,替换我最初提的五类);
- v4 拍板"**不放装备,就跑不了**":能源空=死船不可启用,武器空=接不了战斗,电子空=接不了信号/勘测,防御空=接不了 D3+;T1 = 纯资格件;
- 获取体系(v3 船长令):**远征产材料与蓝图**——`exp_*` 四类材料按任务类型掉落;T1 就地升级(T1+ ≈1.25×);T2 可制造(逆向原图或远征蓝图);**稀有(死亡装备级)= 一次性许可(uses=1,仅远征出,不可售不可拆)**;
- 四层矩阵(§15.6):T1 通货 1.0 / T1+ 1.25 / T2 带代价 1.5 / 稀有机制词条;衍生/势力装备复用底稿换涂装(art_base+palette+decal),**禁随机词条**(与种子可复现冲突);
- 装备的工业接口全部是"给现有系统加行":LICENSE_CATALOG 加行、RESEARCH 逆向/ME/TE 直接复用、碎片喂逆向——零新建系统。

### 4.3 舰长(§9,v4g Starsector 制)
普通(5级/3技能槽/最多1个技能升2级)与稀有(7级/5槽/2个)两档;等级=技能点自由分配;11 项技能表(战斗3/勘测2/打捞2/护航1/通用3);技能只吃队长。获取:酒馆招募(85/15 概率)+**打捞行动解救**(15%,档位随难度,免押金,幸存者信标技能抬概率)。

### 4.4 雇佣兵巢穴(§5.9)
空间站可建造模块(建造页新增按钮,等级制):**每级 +1 行动舰队容量**(Lv1~4 = 1~4 队);未建 = MissionOps 整链锁死;探索等级只管每队船位数(3→4),两条成长线独立。

### 4.5 任务板三层供给(§5.8,方案 A)
短任务(3-8 分钟)节奏下纯随机板会空窗 → ①**常驻委托**(五大类各 1,冷却=时长×1.5,冷却管理即巢穴容量的含金量)②**轮换委托**(3-4 位,30 分钟刷,稀有 10%)③**发现地点**(发现物解锁任务链,结构已入蓝图、实现排 M3,终点挂稀有子系统)。

### 4.6 海盗联动(§5.10,拍到阶段 1)
阶段 1(M2,定案):叙事统一——敌人=海盗开拓地流派,零机制耦合;阶段 2 留档(MissionOps 内部 pirate_heat 热度);阶段 3 留档(配世界系统 M5 劫掠事件,适配器注入限时委托 + pirate_suppressed 信号反哺 supply_efficiency,玩家从"干瞪眼"变"能出手")。

### 4.7 战报 KILL REPORT(§7,v4u 当前采用版)
对标 EVE killmail 迭代八版收敛(四段式→逐字段→zKillboard 三列复刻→简化+底色→**简化结构×渲染风**):☠渐变头栏 / meta 行 / 头部三方块(徽·像·船)/ 名字+₡大字 / 三列(VICTIM·FITTING·BATTLE 摘要)/ INVOLVED 3 卡(FINAL BLOW 金边徽标)/**LOOT 底色行清单(焚毁红底/掉落绿底+左色条+碎片紫·材料琥珀·₡绿标签)**/存入日志·确认收取双按钮。
- **内容 seed 随机生成**(v4v):NPC 名池+诨号、伤害分布、掉落清单、战报模板句——同 seed 逐字复现;
- **头像体系**(v4w 定调:手绘资产,不自动生成):头像挂在**角色**上——舰长/海盗头目=船长手绘(供给 35~50 张高复用);玩家舰船/杂兵 NPC=**船图**(语义正当);势力=手绘徽记 6~10 枚;无资产期船图/徽记占位,到位一张换一张;
- 过程资产留档:分隔线 y 表/竖线 x 表(像素测量)、23×23 像素肖像画法。

## 5. UI 体系(§16)

**行动准备窗**(1248×688 悬浮窗,三分页):
- **装配页**:左舰船缩略卡列表(列表即切换)/ 中上舰船 CG / 中下**放大的线稿船(≈3.6×)+ 四个圆形发光槽直接叠在舰体部位**(艏炮=武器/背=电子/水线=防御/艉=能源,即部位即拖拽目标)/ 右栏装配状态面板+仓库(数量 ×N);
- **舰队页**:拖拽舰船入行动组;组内=舰队配置视图(每舰四槽状态灯);顶部行动组标签排(上限=巢穴等级);
- **酒馆页**:面谈式——左竖版酒馆内景 CG + 中单候选半身像 + 底部候选切换排。

**任务板**:独立悬浮窗(三分区:常驻/轮换/发现),点卡→队伍选择弹层(适配度+门槛校验)→派遣。

**悬浮介绍窗**:双分页(画廊=CG+描述同页/数值=纯硬数据),504×616,锚定弹出。

**样式 SOP**(§16.0):配色锚定 EconTheme 现行常量(做 SOP 必须先读 EconTheme,不许凭空编——v4c 教训);视觉风格 = EVE 渲染风(深蓝青色温/渐变半透明面板/glow/圆形槽/舰船光效);icon 全静态;**信息过载禁令**(一屏一务,空白优先于文字)。

## 6. 美术与资产管线

| 管线 | 用途 | 状态 |
|---|---|---|
| **HTML/SVG → 浏览器渲染 → 截图** | 主占位美术管线(替代 PIL 像素稿) | 三战舰含内构/四子系统/8 建筑图标/巢穴 logo |
| **ASCII photo**(渲染图→亮度→字符) | 酒馆内景占位(tavern);可把任意油画一键转全息风 | tavern_ascii.html |
| **手绘油画 CG** | 正式资产:舰船/舰长头像/舰队出征/酒馆内景,按路径约定替换占位零代码 | 待船长绘制 |
| 像素线稿(PIL) | 退居小图标场合 | tools/gen_*.py |

**CG 路径约定**:`assets/ui/cg/{ship_<船型>, cap_<舰长>, fleet, tavern}.png`;Godot 原生支持 SVG 导入,矢量资产一个文件全尺寸通用。
**动态 icon 结论**:Godot 不支持 SVG/CSS 动画导入;icon 主体烘焙静态,动效仅按"状态信号才动画"原则实现期转 shader/Tween,列表 icon 一律静态。
