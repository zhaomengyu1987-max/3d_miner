## 0. 一句话定位与设计立场

**玩家造船、雇舰长、组编队，把编队派出去接探索/战斗/打捞委托，按现实时间计时，到点结算带回发现与收益**——魔幻放置游戏"远征副本"模式的太空版。它属于**探索系统**，不是经济自动化的延伸。

三条铁律（全文档的数值与设计都从这三条推导）：

1. **不自动化玩家的核心循环**：派遣任务不挖矿、不倒货、不跑运输。玩家亲自飞进碎冰带开光束挖矿是本作核心体验，任何"替玩家挖矿"的系统都是自我贬值（竞品敢做是因为它没有手动玩法可贬值）。
2. **奖励走"进度/发现/稀缺"，不走大宗货币**：大头是探索点、发现物、蓝图碎片、情报；信用点只是添头，封顶为同时长手动收益的 15%。
3. **出任务 = 船锁定**：编队在外，船不可卖、不可拆、不可另派。"队伍在外面"的取舍感是这套系统的游玩核心。

## 1. 边界声明（独立性的具体含义）

| 邻居系统 | 关系 | 允许的接触面 | 明确禁止 |

## 2. 概念模型（四实体 + 生命周期）

```
舰长 Captain ──担任队长──▶ 编队 Team ◀──编入船位── 玩家建造的舰船（longbow/raven/ram/logistics）
                               │
                               ▼ 派遣（锁定船 + 锁定舰长）
                            任务 Mission（任务板上选）
                               │  计时：started_wall + duration
                               ▼
                            结算 Resolution（种子掷骰：大成功/成功/部分成功/失败）
                               │
                               ├─▶ 奖励：探索点 EP / 发现物 / 蓝图碎片 / 情报 / 小额 ₡
                               ├─▶ 损耗：船体受损度 → 维修费 ₡；舰长重伤 → 休养
                               └─▶ 报告：结算报告弹窗 + 发现物入图鉴
```

- **舰长**：雇来的（招募池刷新候选人），四档位 × 五特长；当队长才生效，单人不成队。
- **编队**：1 名队长舰长 + 1~4 艘玩家造的船。船型构成决定任务适配度。
- **任务**：任务板上的委托卡片，有难度档 D1-D4、时长、编队需求、风险、奖励表。
- **发现物**：探索系统的"进度资产"（星域测绘、遗迹坐标、深空信号源……），M1-M3 只是图鉴数据 + 探索点，未来星图消费。

## 5. 数值框架

### 5.1 时间锚点

- **一切周期量以现实时间（墙钟秒）为口径**，游戏日（240 秒/日）只作显示换算（"约 2.5 游戏日"）。
  这是方案 A 的直接推论（§6.1）：否则离线一晚 = 120 游戏日，任何"按游戏日"计的佣金/过期都会被烧穿。
- 时长三档：短 **3-8 分钟** / 中 **10-25 分钟** / 长 **30-60 分钟** [占位]。

### 5.2 成功率模型

```
P = clamp(base(D) + 舰长加成 + 编队适配 + 探索等级加成 − 风险修正, 5%, 99%)

base(D)：      D1 = 0.85   D2 = 0.75   D3 = 0.65   D4 = 0.50
舰长加成(v4g)： 稀有舰长基础 +5%（普通 +0）；特长与任务偏好匹配再 +10%；
               技能加成另计（§9.2，编队取队长技能，合计仍受 99% 封顶）
编队适配：      任务 def 列出"需求船型标签"，每个满足 +5%，上限 +15%
               （船型标签：长弓=突击 / 渡鸦=电子 / 攻城锤=重装 / 后勤=支援）
装备加成(v4 改)： **默认无**——装备是资格门槛（§15.4，不放就跑不了）；
               仅 T2/稀有件带小额成功率修正，编队合计上限 +12%
探索等级加成：  L2 +2% / L3 +4% / L4 +6% / L5 +8%
风险修正：      写死在各任务 def 的 risk 字段（低 0 / 中 5% / 高 10% / 极高 15%）
```

示例：D3 窝点清除（base 0.65，risk 高 −10%），王牌战斗舰长（+15%+10%），编队 2 长弓 1 攻城锤
（标签全中 +15%），L3（+4%）⇒ P = 0.65 − 0.10 + 0.25 + 0.04 = 0.84。

结算区间：`roll = 种子 RNG ∈ [0,1)`；`roll < P×0.3` 大成功（奖励 ×1.25）；`< P` 成功（×1.0）；
`< P + (1−P)×0.5` 部分成功（×0.6 + 全员轻伤）；否则失败（无奖励 + 全员损伤 + 舰长重伤概率）。

### 5.3 风险与损耗

- **船**：失败损伤度 20-40% [占位]，部分成功 10%；维修费 = 船价 × 损伤度 × 0.1，结算时直接扣 ₡（钱包不足则挂账，出任务资格冻结至还清）。防御子系统按 §15.4 相对减免。**M1-M3 船不损毁**——永久损失留给后期单独拍板。
- **舰长**：失败 50% 概率、部分成功 20% 概率重伤 [占位]；重伤休养（现实分钟 = 任务时长 × 2）后自动归队，不死亡。M3 再考虑"舰长永久损失+保险"玩法。
- **任务超期**：编队忘在任务上不存在（计时到点自动结算），但**任务板上的委托会过期**（过期即消失，编队没派出去就不损失）。

### 5.4 舰长经济

| 档位 | 雇佣押金 | 任务分成（货币奖励的） | 解雇 |
|---|---|---|---|
| 普通 | 2,000 ₡ | 20% | 退还 50% 押金 |
| 稀有 | 12,000 ₡ | 20% | 退还 50% 押金 |

舰长成长：出任务 +exp（成功 30 / 部分 15 / 失败 5）[占位]；升级曲线 L_n = 100 × n^1.5；每级 +2% 成功率（叠进 §5.2 舰长加成，与档位加成并行）；L5/L10 各解锁一个**特长强化**（占位：如战斗系"先手压制"——战斗任务风险修正减半）。

### 5.5 奖励表（四轴 + 锚点）

手动收益锚 H₀：护卫舰自动采矿 5 单位/秒 × 矿均价约 4 ₡ ≈ **20 ₡/秒 ≈ 4,800 ₡/游戏日/艘** [占位，待实测校正]。铁律 2 的量化：**单任务货币奖励 ≤ 时长(分钟) × 12 ₡ × 15%** ⇒ 10 分钟任务货币封顶约 18 ₡?——不对，重算：10 分钟 = 600 秒 × 20 ₡/秒 = 12,000 ₡ 手动收益，15% = 1,800 ₡。**修正：单任务货币奖励 ≤ 时长(秒) × 20 ₡/秒 × 15%**，10 分钟任务 ≤ 1,800 ₡，1 小时任务 ≤ 10,800 ₡ [占位]。

| 轴 | 内容 | 占比（设计目标） | 说明 |
|---|---|---|---|
| 进度 | 探索点 EP（D1: 5 / D2: 12 / D3: 25 / D4: 50） | 主奖励之一 | 推等级 → 解锁难度档/船位/板位（§5.6） |
| 发现 | 发现物（勘测/信号类必得；其余 10-20% 概率） | 主奖励之一 | 图鉴数据 + 部分发现物触发任务链（M3） |
| 稀缺 | 蓝图碎片（战斗/打捞类 30-60% 概率 1-2 片）、情报点 | 稀缺吸引 | 碎片 → 逆向素材包（§5.7）；情报点 M2 定用途 |
| 货币 | ₡（≤ §5.5 公式封顶） | 添头 | 分成扣舰长 20% 后入玩家钱包 |

### 5.6 探索等级曲线 [占位]

L1→L2: 50 EP；L2→L3: 150；L3→L4: 400；L4→L5: 900。解锁：L2 = D2 任务 + 板面 5 张；L3 = D3 + 稀有委托位；L4 = **每队第 4 船位**；L5 = D4 + 深空信号链（M3 内容）。
  - **维度澄清（v4f）**：探索等级管**每队船位数**（3→4）；**行动舰队数量上限**由空间站「雇佣兵巢穴」建筑等级决定（§5.9）——两条成长线独立。

### 5.7 蓝图碎片 → 逆向素材

碎片按目标蓝图分组（`frag_product_*` / `frag_ship_*` / `frag_equip_*`——v2 增装备族，§15），每种凑满 N 片（产品 5 / 舰船 8 / 装备 4）[占位] 可兑换 1 份"逆向素材包"——使用后直接给 `RESEARCH` 逆向研究 +1 批进度（对接现有 reverse 系统），**不直接产出蓝图**。已拥有原图/已逆向满的目标不出碎片（查询 Economy 蓝图库存）。

### 5.8 任务板：三层供给（v4h 船长拍板方案 A）

短任务节奏（3-8 分钟）下纯随机板会空窗，任务板改为**三层供给**：

**① 常驻委托（保底层，M2）**
- 五大类各 1 个基础任务**永远在板**：勘测 / 战斗 / 打捞 / 护航 / 信号（即 §8 表中各类型的基础条目）。
- 接完进入**冷却 = 任务时长 × 1.5**（船长拍板起步值；如 8 分钟任务冷却 12 分钟）——冷却管理成为节奏核心，舰队容量（巢穴等级 §5.9）的含金量由此兑现：队越多，冷却轮转越密。
- 常驻任务无过期概念（做不完就一直挂）。

**② 轮换委托（惊喜层，M2）**
- 板面 3-4 个轮换位；**在线每 30 现实分钟**刷新 + 读档时距上次刷新 >30 分钟则补刷一次 [占位]；离线不刷板（§6）。
- 轮换池 = 高难度变体（D+1 同类型）/ 跨类特殊委托 / **稀有委托**（10% 概率，奖励 ×1.8、24 小时过期）。
- 委托过期：普通 2 现实小时，稀有 24 小时 [占位]。

**③ 发现地点（进度层，结构即入蓝图、实现排 M3）**
- 探索发现物（§5.7 / §8 信号任务产出）解锁**固定地点**：海盗窝点 / 远古残骸群 / 异常信标阵……每个地点是一条任务链（2-4 个递进任务），终点奖励挂稀有子系统（§15.5）。
- 一次性通关为主，高价值地点可周常复刷 [占位]。
- 地点数据落在 `discoveries`（kind="site"），M3 前只是图鉴条目，M3 起出现在任务板第三分区。

### 5.9 雇佣兵巢穴（空间站建筑，v4f 船长令）

**「雇佣兵巢穴」= 空间站可建造模块**（与建造厂同类的可建造单位，`GameData.MODULES` 新增 `hive`），**等级制**（像机库/研究站），**每升一级容纳更多行动舰队**：

|---|---|---|---|
| Lv1 | 1 队 | commonA×300 + cabin×2 | 300s |
| Lv2 | 2 队 | commonA×800 + truss×4 + cabin×3 | 600s |
| Lv3 | 3 队 | commonD×1500 + truss×8 + ecu×3 | 900s |
| Lv4 | 4 队（满） | commonD×3000 + ecu×6 + fueltank×2 | 1200s |

- **容量语义**：行动准备窗·舰队页可同时编辑/在途的行动组数 = 巢穴等级；Lv0（未建）时 MissionOps 整链锁死（入口按钮灰显 + 提示"建造雇佣兵巢穴以解锁探索派遣"）——和"无机库无货舰"同一设计语言。

### 5.10 海盗联动（v4h：拍到阶段 1，路线留档）

与世界的海盗（开拓地 / 世界系统 M5 劫掠事件）分阶段联动，**耦合方向只允许"信号 + 适配器"**（§1 铁律不变）：

- **阶段 1（定案，随 M2 实装）——叙事统一**：战斗/打捞任务敌人统一为海盗开拓地流派（散匪→劫掠者快船、窝点→私掠者前哨、蜂巢清巢→海盗巢穴）；任务文案以委托方视角提及"近期劫掠加剧"。**零机制耦合**。
- **阶段 2（留档，M3+ 再议）——海盗热度**：MissionOps 内部变量 `pirate_heat`（时间上涨 / 清剿下降），影响轮换层海盗类委托的频率、奖励与难度变体。仍不读世界系统。
- **阶段 3（留档，配世界系统 M5）——劫掠事件双向桥**：WorldState 劫掠事件经适配器注入限时"防御/清剿劫掠舰队"委托；玩家完成 → MissionOps 发 `pirate_suppressed` 信号 → WorldState 缓解 supply_efficiency 惩罚 → 货舰频率回升。玩家从"干瞪眼看货舰被劫"变为"可以出手"。

## 6. 时钟与离线结算

### 6.1 时钟方案 **[拍板点 1]**

- **方案 A（推荐，本蓝图按 A 写）**：任务计时走**墙钟**。派遣时记 `started_wall`，到点即结算——在线时由 `_process` 心跳查，离线时读档一次算清。任务时长即真实等待。理由：用户明确要"关游戏继续玩"；且放置派遣品类的核心快感就是"下线前把队伍派出去，上线收货"。
- 方案 B：跟随 `Economy.day`（游戏日），离线停摆。在线一致性最好，但直接违背诉求，仅作对照保留。

**方案 A 的连带决策**：一切"按日"的量（佣金/板刷新/过期）一律改按现实时间或改为事件驱动（§5.4 已按此执行：无日薪、有分成）。

### 6.2 离线结算流程

```
读档 → gap = now − saved_at_wall
  ├─ 对每个 active 任务：ends_wall ≤ now 的全部结算（种子已定 ⇒ 结果与在线结算逐位一致）
  │    └─ 全部奖励/损耗照常入账，汇入离线简报
  ├─ 在途未完的：显示剩余时间
  ├─ 招募池/任务板：过期的清掉，不补刷（上线后按 §5.8 补刷）
  └─ 弹离线简报："离线 6h12m：一队完成『航道清剿』(成功, +620₡, 蓝图碎片×1, EP+12)；
                  二队『深空测绘』还剩 18 分钟"
```

无上限设定：任务本身时长就是天然上限（在途最多同时 = 编队数），**不需要**竞品那套 8 小时离线封顶——那是给"挂机经济连续结算"设计的，我们的离线只有离散的几个任务在走。

### 6.3 前置公共件：GameSave（极简存档）**[拍板点 2]**

**现状确认：本作目前零持久化**——全仓只有 `SettingsPanel.gd` 存了 `user://settings.cfg`（显示设置），经济/建造/舰队状态全部会话级。离线结算（无论派遣还是离线矿积累）都卡在这个缺口上。

方案：新增 `scripts/save/GameSave.gd`（autoload），**节注册制**，30-50 行：

```gdscript
# 各系统调 GameSave.register_section("missionops", callable_get_state, callable_apply_state)
# GameSave 负责：读 user://save.json → 分发各节 apply；每 60s + 关键操作后（由各系统显式调 GameSave.touch()）落盘
# JSON 顶层：{ "version": 1, "saved_at_wall": float, "sections": { "missionops": {...}, "economy": {...} } }
```

- M1 只接 MissionOps 一节跑通；离线矿积累（独立功能）届时给 Economy 落一节即可，MissionOps 不感知。
- 竞品的存档纪律直接抄：**写盘前版本号校验、读档失败挂起写入不覆盖旧档、日志不落档**。
- [竞品] `savedAtWallMs` 放顶层，各节共用。

## 9. 舰长系统细则（v4g：Starsector 式技能制，船长令）

### 9.1 两档舰长

| 雇佣押金 | 2,000 ₡ | 12,000 ₡ |

- **等级 = 技能点**：每升 1 级 +1 点，自由分配——解锁新技能 1 点；已解锁技能升 2 级再花 1 点（**每技能仅一次额外升级**），2 级技能数受档位上限约束。

### 9.3 打捞解救

- **打捞类任务**（mo_salvage_*）结算成功时，基础 **15%** [占位] 概率解救一名被困舰长（结算报告高亮演出："残骸深处，一具休眠舱的灯还亮着"）。
- 解救舰长档位按任务难度掷：D1-D2 → 普通 100%；D3 → 普通 50% / 稀有 50%；D4 / 稀有委托 → 普通 30% / 稀有 70% [占位]。初始等级 = 难度档 + 0~2 随机；自带 1 个已解锁技能（随机）。
- **免押金直接入驻**（回报打捞玩家）；「幸存者信标」技能抬高解救概率（§9.2）。
- [拍板：解救舰长是否计入舰长数量上限——默认暂不设上限，押金/分成即自然约束]

### 9.4 状态机（不变）

- `idle → on_mission（随编队）→ idle / resting（重伤）`；resting 期间不可派遣、不占编队（编队自动解散回空闲）；可随时解雇（退 50% 押金，在途则不可解雇）。
- **同一时刻约束**：一名舰长只能带一队；一艘船只能在一个编队；一个编队只能在一个任务。

## 11. 防贬值与防滥用清单

1. 派遣**永不产出**矿石/组件/产品实物（碎片、情报、EP、远征材料 `exp_*` 是独立 id 段的虚拟物品——v3 增远征材料族）。
2. 货币奖励 ≤ 同时长手动收益 15%（§5.5 公式，上线实测后校准系数）。
3. 出任务船三重锁定：不可挂单 / 不可再编队 / 不可拆解。
4. 离线收益与在线**同率**，无离线加成；在途任务数量天然封顶（= 编队数）。
5. 任务板不出现"资源包"类委托（M1-M3；未来若加，走稀有委托 + 独立掉落表单拍）。
6. 碎片兑换走逆向素材（喂 RESEARCH），不直接给成品蓝图；已逆向满的不出碎片。
7. 成功率预估全量展示加成来源（无暗箱），种子存档可复现（争议可查）。
8. 刷新/招募池的随机全部走**带存档的种子 RNG**（[竞品] 禁裸 random：种子+调用次数落档，结果可复现）。
9. 子系统出售口径（v3）：T1 可随货舰出售；T2 可造（常规许可），可否出售 [拍板]；稀有件**不可出售**（任务掉落绑定 + 一次性许可不可售不可拆，§15.3）。

## 12. 竞品对照（Deepseek-EVE：拿了什么，丢了什么）

| 他们的做法 | 我们的处理 |
|---|---|
| AI 核心分身：自动挖矿/打捞无限循环 | **丢弃**（经济克隆会贬值手动挖矿——我们玩家真的在开船） |
| AI 远征任务：锁火力+计时+到点掷骰 | **拿**：这就是本系统的结算原型 |
| 约束内自主决策（胜率 ≥80% 才接单） | **改造**：竞品是 AI 替玩家选，我们让玩家自己选、系统只算胜率并展示（选择感留给玩家） |
| 相位机 + 时间累加器（`phase/acc_ms`） | **拿**：结构照抄（§3 的 active 任务就是简化版相位机——我们只有一段计时，不需要多相位） |
| 种子 RNG + 禁裸 Math.random | **拿**（§11.8） |
| 每拍幂等自愈对账（船没了/被切走→清理归还） | **拿**：读档与每分钟对账：编队里的船被卖/舰长被解雇等坏态一律安全回收（任务中断、船解锁、舰长回 idle） |
| 离线 8h 封顶 + 30s 分片推进 | **丢**：我们离线只有离散任务结算，不需要连续模拟（§6.2） |
| 核心是共享稀缺资产（副船+工业共用上限） | **改造**：舰长只服务派遣（独立成长线）；"稀缺资源卡派遣频率"的定位由编队船位/舰长档位承担 |
| 六槽高/中/低 + 插件 + CPU 预算（EVE 式装配） | **改造**：简化为 4 子系统槽（能源/电子/武器/防御，§15）——槽少而精，服务派遣构建，不做 CPU/资源预算 |

## 14. 舰船启用与命名（v2 新增）

- **启用**：建造完成的船默认是库存商品（可卖）。玩家在机库/装配台点「启用」→ `Economy.take_ship_item(def_id)` 库存 -1，生成实例进入名册（§3 `fleet` 节），自动分配编号名。
- **命名规范**：全局计数器 `ship_name_counter` 递增，"**001号**""**002号**"……退役**不回收编号**（同舰船舷号语义）。正式命名规范（自定义名/前缀/长度限制）以后专拍 [拍板]，当前只做自动数字名。
- **退役**：名册选船「退役」→ 自动卸下全部子系统回仓库 → `give_ship_item` 转回库存商品可卖。在途任务的船不可退役（任务锁优先）。
- **双锁关系**：编队只能从名册选船；启用船受"任务锁 + 装配锁"约束——出任务时槽位冻结不可换装，换装必须在港内空闲状态。

### 15.3 获取体系（v3 按船长令重修：远征产材料/蓝图，分层渠道互斥）

总原则：**每一层绑定一条独立的获取循环，且升级与制造的关键材料都从远征来**——派遣系统是全部装备成长的源头，工业链负责"加工"，远征负责"给料"。

| 层级 | 获取方式 | 蓝图/许可来源 | 关键材料 |
|---|---|---|---|
| T1 基础型 | 许可制造（常规许可 30 次/张） | `LICENSE_CATALOG` 货舰铺货（不变） | 常规 BOM（§15.2） |
| T1+ 升级型 | **就地升级**：T1 件 + 远征材料 ×N + ₡，在装配台执行 | 无需蓝图（升级即服务） | 远征材料（§15.6） |
| T2 高级型 | **制造**：常规许可 + BOM（稀有矿 + 远征材料） | 逆向原图（碎片→素材→RESEARCH）或远征蓝图整张掉落 | 远征材料 + rare 矿 |
| 稀有（死亡装备级） | **一次性许可制造**：许可用一次即毁 | 许可证只从远征出（整张掉落或碎片兑换），市场无售 | 远征材料（大剂量）+ rare 矿 |

- **远征材料**（`exp_*` 独立 id 段，§11.1 已随之修订）：按子系统分四类——`exp_power` 超导环流圈（能源）/ `exp_elec` 相位谐振器（电子）/ `exp_weapon` 火控枢纽（武器）/ `exp_defense` 装甲晶格（防御）[占位名]。掉落规则：**任务类型决定材料类型**（战斗类掉 exp_weapon、信号/勘测类掉 exp_elec、护航类掉 exp_defense……），难度档决定数量（D1 0-1 / D2 1-2 / D3 2-4 / D4 4-6）[占位]。
- **T1+ 升级规则**：每件 T1 最多升一级（T1→T1+，数值 ≈1.25×，无副作用）；升级不可逆；升级后名称带"·升级型"后缀（"标准反应堆·升级型"）；外观复用 T1 线稿 + 色带（§17 美术复用管线）。
- **一次性许可**：复用现有许可次数制（产品 30 次/舰船 3 次）新增 **uses=1 档**；`lic_eq_rare_*` 只从远征出（D4 任务小概率整张掉落 / 碎片 ×N 兑换），**不可售、不可拆**——每多造一件稀有装备就必须再打一轮远征，通胀阀门天然锁死。
- 逆向研究（§5.7）仍是 T2 蓝图的主渠道；远征整张蓝图掉落是快渠道（更稀有）。

### 15.4 装备语义：资格门槛优先（v4 船长定案："不放装备，就跑不了"）

**装备不是百分比加成，是资格门槛。** 子系统装没装，决定船"能干什么"，而不是"干得好百分之几"：

| 槽位 | 空槽的后果（硬门槛） |
|---|---|
| 能源 power | **船无法启用**（启用按钮灰显，提示"缺能源子系统——死船"）；启用制度天然保证编队全员有能源（§14） |
| 武器 weapon | 编队**接不了战斗类任务**（派遣按钮灰显，缺口清单提示"缺武器子系统 ×N"） |
| 电子 elec | 编队**接不了信号/勘测类任务** |
| 防御 defense | 编队**接不了 D3+ 任务**（高危必须全员带防御） |

- **数值修饰退居次席**：T1/T1+ 是**纯资格件**，不带任何百分比；只有 T2 与稀有件携带小额修饰（成功率/时长/损伤 ±5~15%），编队合计上限 +12%（§5.2 公式的"装备加成"行按此口径）。资格件让"舰队成军"有刚性制造需求，远征材料循环被需求锁死——与防贬值三铁律更一致。
- **任务 def 增 `equip_req` 字段**（§8 表随附说明）：战斗类 `{weapon:≥1}`、信号/勘测类 `{elec:≥1}`、D3+ `{defense:全员}`；校验在派遣确认时做，不满足灰显 + 缺口清单。
- **叙事补偿保留**：结算报告仍按装备生成战报文本（"辉钼火控组锁定要害"）——门槛决定"能不能打"，报告把"怎么打的"演出来。
- **明确不做**：不碰 3D 挖矿/无人机/货舰数值；不上 CPU/资源预算类约束（竞品有，我们砍）。

### 15.5 稀有子系统（死亡装备级，2 件起步）

获取双轨：**任务必掉整件（首件捷径）** 或 **一次性许可制造（复现路径，§15.3）**——两件都要打远征，区别只是"脸好"还是"肝够"。

| id | 名称 | 槽 | 来源 | 特效 |
|---|---|---|---|---|
| eq_rare_phantom | 相位幽灵阵列 | 电子 | mo_signal_grid（D4）掉落 / 一次性许可制造 | 信号/勘测 +15%；编队首次进入新难度档必出发现物 |
| eq_rare_bastion | 移动堡垒核心 | 防御 | mo_rare_hive（稀有）掉落 / 一次性许可制造 | 全队损伤 −70%；失败时船免吃损伤 |

后续扩至 6-8 件，与任务链绑定（每条链的终点奖励是一件稀有子系统）[占位]。

### 15.6 四层装备矩阵（v3 定稿：区分靠"定位 + 渠道"，不靠纯数值）

| 层 | 定位 | 强度锚 | 唯一获取循环 | 可交易 | 线稿表现 |
|---|---|---|---|---|---|
| T1 基础型 | 通货，工业常规产出 | 1.0 | 许可制造（市场） | ✅ 随便卖 | 现有：老实工业感 |
| T1+ 升级型 | 就地强化，无副作用 | 1.25 | 远征材料就地升级 | [拍板] | T1 底稿 + 色带 |
| T2 高级型 | 纵向强化**带代价** | 1.5 | 逆向原图 / 远征蓝图 → 制造 | [拍板] | 更锐几何 + 类别色发光线 |
| 稀有（死亡装备级） | 机制性独特词条 | 特殊 | 一次性许可制造 / 任务掉落 | ❌ 绑定 | T2 底稿 + 纹章涂装 |

- **每层的"为什么还用它"**：T1 赢在便宜可量产；T1+ 赢在零副作用零风险；T2 强但 BOM 贵、有副作用（如 eq_weapon_mk2 损伤 +10%）；稀有件是机制独特性（数值之外的效果），且每一件都要新打一轮远征。
- **衍生/势力命名前缀制** [占位]：升级型"·升级型"后缀；特化衍生用"紧凑型/超载型/军用规格/实验型"前缀；势力装"帝国规格/联盟规格"前缀（M4 阵营委托适配器接入后实装，def 带 `faction` 标签，MissionOps 本体不感知阵营——§1 独立性不破）。
- **美术复用管线**：装备 def 带 `art_base` + `palette` + `decal` 三字段——衍生/势力/升级型不画新图，复用底稿换涂装（生成脚本加调色参数即可）；真正新画的只有 T2 底稿和稀有件。
- **红线**：不做随机词条（roll）装备——与"种子可复现、争议可查"（§11.8）冲突；独特感用机制词条表达，不用随机数值。

### 16.2 交互规格

- **拖拽装配**：Godot 原生 Control 拖拽三件套（`_get_drag_data` / `_can_drop_data` / `_drop_data`）。拖拽源 = 右栏仓库条目或已装槽位；投放目标 = 四槽或右栏（卸下）。放下即穿/卸并实时刷新统计条；**不匹配的槽在拖拽悬停时灰显**（`_can_drop_data` 返回 false + 视觉反馈），子系统与槽位按 category 字段校验。
- **悬浮介绍窗 = 双分页 CG 画廊**（v4c，船和子系统同一窗体，504×616）：标题栏下**可点击分页「画廊 / 数值」**：
  - **画廊页 = 图与文同页**：上半 **CG 图区 472×300**（任意比例 letterbox 居中，油画任意画幅都放得下；本作没有实际战斗场景，**CG 与描述共同承载玩家想象**），下半**装备自身描述**（每件装备一段文案，紧贴图下，给足行数）；图注一行可选；
  - **数值页 = 纯硬数据**：资格行加粗（门槛语义，§15.4）→ 数值修饰 / 已装于 → 获取方式一行（来源压缩，不进画廊页）；
  - **CG 占位与替换**：占位期 = 线稿居中 + letterbox + 角标；船长的油画 CG 按路径直接替换（`assets/ui/cg/<装备id>.png`，船 = 船型 id），零代码改动；
  - **hover 船**：同款窗体——画廊页 = 舰船油画 + 船舶描述，数值页 = 舷号 / 资格达标状态 / 已装子系统 / 当前任务；
  - **行为**：0.25s 延迟弹出（大窗不宜秒弹）；**锚定弹出、不跟随鼠标**；屏幕边缘自动翻转；移开即收。
- **配图（占位）**：`assets/ui/placeholders/` 下 8 张像素线稿（4 船侧视 128px + 4 子系统图标 96px），由 `tools/gen_placeholder_art.py` 生成——**路径与文件名固定不变，后续船长替换正式美术时零代码改动**（Node2D/TextureRect 换图即可）。

### 16.3 实现纪律清单（实现时逐条对照）
